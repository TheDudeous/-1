Для установки хуков надо установить pre-commit через pip ($ pip install pre-commit), потом создать yaml конфиг, посмотреть, нормально ли он сконфигурирован, потом запустить эту команду
$ pre-commit install
Причем также нужно сделать команду
$ git add .pre-commit-config.yaml 
Чтобы все норм работало

Я также использовал pre-commit autoupdate чтоб rev норм поставил и перестал жаловаться на неё
И все можно коммитить кайфовать
